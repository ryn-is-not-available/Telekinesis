# Telekinesis

A hands-free PC control system that tracks your hand movements via computer vision to drive your cursor, click, and navigate without touching hardware.

## 🚀 Getting Started

### Prerequisites

Make sure you have Python installed, then install the initial dependencies:

```bash
pip install opencv-python mediapipe pyautogui pynput numpy
```
